# 规则推理子智能体优化设计

> 2026-07-28 · brainstorm 产出 · 子智能体优化系列(3/4)
> 依据:用户参考资料(docs/参考资料2.txt)定义的违规判定逻辑

## 背景

规则推理子智能体(`rule-reasoning`)框架完整(法规匹配 + 工艺校验 + 专家推理 + 结论生成),但和参考资料不一致:
1. **违规类型**:AGENTS 写 5 类(插瓶/稀释/暗管/虚假停产/公式篡改),资料是 4 类(插瓶/拟合/稀释/逃避)——多了暗管/虚假停产、丢了恶意逃避、人工拟合被叫成公式篡改
2. **工艺规则缺一条**:缺"多指标同步突降"(稀释排放关键判据)
3. **判据不精确**:AGENTS 用"相关性<0.3",资料是"标准差阈值 + 异常特征"(如 pH std≤0.1 + 平稳异常 → 插瓶)
4. **嫌疑等级没按矩阵**:资料有"合规性×工艺违背"4 档矩阵
5. **异常特征对接不上**:异常检测 redesign 输出 5 类特征,规则推理现状读旧 type
6. AGENTS 过时(预加载/skill_view,通病)

本设计:**全面对标资料**(4 类违规 + 4 条工艺规则含精确判据 + 嫌疑矩阵 + 异常特征对接),缺数据部分(工况/停产申报)空着标记。

## 设计原则

1. **双层判定**:数据层异常(异常检测)≠ 语义层违规(规则推理);两层都判才成违规结论
2. **知识驱动**:法规库 + 工艺规则库 + 违规模式特征库 + 专家经验库(都在 `shared/knowledge/`)
3. **对标资料**:违规类型、工艺规则判据、嫌疑矩阵按资料定义
4. **缺数据透明**:拟合降级、逃避 TODO,在输出标记 `missing_data`

## 违规类型(4 类,初版完整度)

| 违规模式 | 初版状态 | 依据 |
|---|---|---|
| **插瓶干扰** | ✅ 完整 | pH-COD 协同 + 氨氮-总氮转化(纯水质数据) |
| **稀释排放** | ✅ 完整 | 质量平衡 + 多指标同步突降(纯水质数据) |
| **人工拟合** | ⚠ 简化 | 只看趋势异常(缺工况数据,降级;标记"需工况数据增强") |
| **恶意逃避** | ❌ TODO | 暂不判(需停产申报数据;标记 TODO) |

## 工艺规则(资料精确判据)

| 规则 | 判据(资料) | 异常特征组合 | 判向 |
|---|---|---|---|
| pH-COD 协同 | pH std≤0.1(范围0.05–0.2) 且 COD std≤5.0 mg/L(范围3–10) | + 平稳异常 | 插瓶 |
| 氨氮-总氮转化 | 氨氮突降而总氮基本不变(违背硝化规律) | + 突变 | 插瓶 |
| 质量平衡 | 去除率偏差 > 0.2(范围0.1–0.3) | + 趋势/突变 | 稀释 |
| 多指标同步突降 | 2+ 污染物(COD/氨氮/总磷/SS)同步下降 >50%(范围30%–70%) | + 突变 | 稀释 |
| (趋势→拟合) | 趋势异常 + 工况无变化但数据均匀变化 | + 趋势 | 拟合(降级,无工况) |
| (停产→逃避) | 排放正常 + 企业申报停产/停运 | — | 逃避(TODO) |

## 异常特征对接

读异常检测输出的 5 类特征(`anomaly_result.anomalies[].features`):
- 平稳 / 突变 / 趋势 / 周期 / 高频波动
- **组合特征 + 工艺规则 → 违规模式**。如检出 [平稳 + 突变] → 查 pH-COD 协同 → 判插瓶

## 嫌疑等级矩阵(资料)

| | 工艺违背 | 工艺无违背 |
|---|---|---|
| **法规违规**(超排放标准阈值) | 高风险 | 低风险 |
| **法规未违规** | 中风险 | 无违规 |

## 缺数据标记(初版)

- **人工拟合**:无工况数据 → 降级(只看趋势异常),输出 `missing_data` 标"需工况数据增强"
- **恶意逃避**:无停产申报 → 暂不判,标 TODO(等你申请到数据补)
- 插瓶 + 稀释:纯水质数据,初版完整

## 决策记录

- **4 类违规对标资料**:去掉 AGENTS 的暗管/虚假停产/公式篡改,统一为插瓶/拟合/稀释/逃避
- **工艺规则用资料判据**:标准差阈值 + 异常特征(非简单相关性),更精确
- **嫌疑矩阵**:合规性 × 工艺违背 → 高/中/低/无(资料定义)
- **异常特征对接**:读异常检测新 5 类特征,组合 + 工艺规则判违规模式
- **缺数据透明**:拟合降级、逃避 TODO,标 `missing_data`,初版不阻塞(插瓶/稀释完整可用)
- **异常 ≠ 违规**:异常检测给特征,规则推理查知识库判违规模式 + 嫌疑等级

## 范围

本 spec 仅规则推理子智能体(4 类违规 + 4 条工艺规则 + 嫌疑矩阵)。数据感知(1/4)、异常检测(2/4)见各自 spec。处置执行(4/4)后续 brainstorm。
