# 全系统助手迁入主智能体 Skill

## 已确认的方向

右下角助手保留现有界面、主题及独立会话，但理解请求和生成候选动作统一交由现有 Hermes 主智能体及一个系统交互 Skill。不是新增角色、子智能体、服务进程或模型调用通道。主页面 AI 仍承担专业研判。

## 迁移前代码事实

- 8000后端的 `assistant_service.respond`目前直接调用模型；并非独立进程，但形成了第二套模型调用逻辑。
- `scripts/start_agent.py`在8642端口持有单个 `master_agent`，同步与流式查询共用锁及 `AgentTurnGuard`。
- `workspace/AGENTS.md`按动作/问答分流，已有 `skills/action-command-core`；它的旧actionData协议和新侧栏候选动作协议不同，不能直接替换。
- 主智能体目前可触达编排工具和部分MCP。仅加一份Skill不能构成权限隔离。

## 请求流

侧栏 → 现有8000 `/api/assistant/respond` → 现有8642新增 `/system-assistant/respond` → 同一主智能体定义的会话级隔离实例、同一身份 → 预加载 `system-interaction-core` Skill → 返回经校验的文字/候选动作/专业任务交接。

新增内部路由不是新增服务。8000路由保留作为协议校验与代理，不能在8642失败时回退到直接请求模型。固定帮助资料也迁入Skill，避免两份行为知识。

## Skill与执行边界

- 新增 `skills/system-interaction-core/SKILL.md`，覆盖八类页面入口、页面说明、导航、已支持筛选/定位、策略草稿、事件候选和专业交接。
- 系统交互模式强制加载这一Skill，仍使用主智能体身份；不新建身份文件或角色注册。
- 侧栏本轮不调用任何外部工具：Skill由受信任代码预加载，模型只生成候选。禁止call_subagent、MCP、终端、文件及数据库写工具，检测标注仍经现有执行器和检测接口执行。
- 工具限制必须同时作用于请求可见工具列表和真正工具分发入口；不能仅提示模型“不调用”。不修改全局工具注册表。
- 页面上下文和历史都是不可信数据，不能覆盖执行模式、Skill路径、工具权限或确认规则。
- `system-interaction-core`是新操作规则单一来源；原 `action-command-core`保留旧协议的薄兼容说明，指向新Skill，不再重复维护页面动作规则。专业主页面旧动作接口保持可用，兼容转换集中于代码适配层。
- Python能力schema继续由确定性代码维护；Skill解释能力，不授予权限。前后端仍验证白名单。

## 实例、会话和并发（用户确认的并行修订）

- 共用主智能体类、workspace身份、供应商配置解析和实例工厂；不同会话有隔离的AIAgent运行对象，不是新角色或新服务。侧栏任务ID由服务端生成system-assistant命名空间，专业通道拒绝该保留前缀。
- 初版继续由侧栏提交最近20条文本历史，进入Hermes前构造独立历史，不读写专业session_histories、子智能体结果目录、知识记忆。审计会话分类为system-interaction。
- 每次运行显式传入本轮历史和Skill约束，实例状态不得进入另一会话。侧栏实例不挂专业工具，不操作专业SESSION_DIR、全局进度队列和检测上下文；内存、文件记忆及后台hook也必须隔离或关闭。
- 主页面保留原专业实例和锁；侧栏不获取这把锁。侧栏同会话非阻塞锁串行，不同会话可并行，初始最多2个侧栏执行槽，实例缓存有数量上限和空闲淘汰。忙碌409只用于本会话重复提交或侧栏容量已满，不用于专业请求正在运行。
- 最大迭代2，单轮墙钟60秒；超时仅隔离该侧栏实例。仍存活的线程占用其容量槽和会话锁，真正退出后才销毁/释放，不影响专业实例；不能通过反复超时制造无界线程。
- 验收必须证明专业实例被阻塞时侧栏仍可完成；同名客户端session_id不串历史、工具权限、目录或进度。底层模型容量可能影响时延，但应用层不以全局主锁强制串行。

## 保留的功能

保留侧栏浅蓝玻璃主题、420/560宽度、跨页会话、上下文版本和页面动作执行器；保留事件提议、人工确认、CAS、幂等、审计及未知结果查询，真实写入开关维持false。策略只产生diff草稿，仍由用户在原配置页保存。专业分析只产生主AI草稿，不能在侧栏自动启动四子智能体。

## 返回和失败协议

沿用 `message/actions/handoff/session_id`。保留已修复的纯文字与完整JSON围栏兼容：文字仅展示、无动作；畸形结构、非法动作不执行。共享解析/校验模块独立于模型传输。

409表示侧栏同会话忙碌或侧栏容量已满；503表示现有Agent服务不可达；模型输出不合法返回502；墙钟超时504。日志只记录通道、阶段、异常类别、耗时和任务关联，不记录密钥或完整页面正文。用户看到具体中文提示。

## 验收

1. 单元测试证明8000不再调用chat/completions，8642通过统一主智能体实例工厂创建有界会话实例，不新增独立模型调用实现、身份或服务。
2. 伪造工具调用、提示注入、模型要求call_subagent/MCP时，真实handler调用次数为零。
3. 主页面与侧栏即使提交相同session_id，历史、记忆、结果目录仍不混用。
4. 专业运行与侧栏真实重叠、侧栏两会话可重叠；同会话重复、容量限制和超时隔离可测，孤儿线程未退出前不会复用实例或释放槽。
5. 现有216项前端、48项助手/事件后端基线及新增回归通过；专业流式/生命周期回归通过。
6. 使用真实浏览器与真实模型连续至少12轮及刷新恢复验证；导航候选点击后真实定位。事件/配置写入仅夹具验证。
7. 服务进程/端口没有增加；主智能体服务停止时侧栏明确不可用，不偷偷走旧模型通道。

## 工作区约束

继续在原目录现有开发分支执行；保留混合工作区，不创建worktree，不提交/合并/推送。实施状态和验证证据见同日实施计划执行记录。既有服务在实施结束后定向重启并验证，不新增启动项。
