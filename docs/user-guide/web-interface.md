# Web界面用户指南

## 快速开始

### 1. 启动服务

需要同时启动三个服务：

```bash
# 终端1 - Web界面服务器
python middleware/web_interface.py

# 终端2 - 查询接口（自然语言分析）
python middleware/query_interface.py

# 终端3 - 监控接口（实时数据）
python middleware/app_orchestrator.py
```

### 2. 访问界面

打开浏览器访问: **http://localhost:8080**

## 功能说明

### 🔍 智能查询

使用自然语言查询废水监测数据，LLM会自动解析意图并调用相应的子智能体进行分析。

**支持的查询类型：**
- 相关性分析：查询两个或多个指标之间的关系
- 异常检测：识别数据中的异常模式
- 趋势分析：分析指标随时间的变化趋势

**示例查询：**
- "过去24小时pH和COD之间的相关性怎么样？"
- "检测最近一周的数据异常"
- "分析氨氮和总磷的变化趋势"
- "进水和出水的总氮有什么关系？"

**查询流程：**
1. LLM解析查询意图
2. 获取指定时间范围的历史数据
3. 调用数据感知子智能体进行数据治理
4. 调用异常检测子智能体进行分析
5. LLM整合结果生成自然语言报告

### 📊 实时监控

查看系统当前的监测指标和分析状态。

**显示内容：**
- **指标卡片**：进水和出水的实时指标值
  - pH值
  - 化学需氧量 (COD)
  - 总氮 (TN)
- **系统状态**：当前系统运行状态（正常/异常/告警）
- **趋势图表**：异常和违规数量的时序趋势

**更新频率：** 每5秒自动刷新

### 📈 分析报告

查看系统生成的历史分析报告。

**报告内容：**
- 分析时间
- 异常数量
- 违规数量
- LLM生成的详细分析报告

## 故障排除

### 无法访问页面

**症状：** 浏览器显示"无法连接"

**解决方案：**
1. 检查Web界面服务器是否启动
   ```bash
   python middleware/web_interface.py
   ```
2. 检查端口8080是否被占用
3. 查看防火墙设置

### 查询无响应

**症状：** 点击查询后长时间无响应

**解决方案：**
1. 检查查询接口是否启动
   ```bash
   python middleware/query_interface.py
   ```
2. 查看浏览器控制台错误信息（F12）
3. 确认LLM配置正确（API密钥等）

### 监控数据不更新

**症状：** 实时监控面板显示"--"或不更新

**解决方案：**
1. 检查监控接口是否启动
   ```bash
   python middleware/app_orchestrator.py
   ```
2. 确认有数据流进入系统
3. 刷新浏览器页面

### 服务状态检查

访问 http://localhost:8080/api/web/status 查看所有服务的状态：

```json
{
  "web": {"status": "running", "port": 8080},
  "query_interface": {"status": "running"},
  "monitoring": {"status": "running"}
}
```

## API端点

### 查询相关

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/web/query` | POST | 发送自然语言查询 |
| `/api/web/health` | GET | 健康检查 |
| `/api/web/status` | GET | 服务状态 |

### 监控相关

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/web/monitoring/metrics` | GET | Prometheus指标 |
| `/api/web/monitoring/analysis` | GET | 分析结果 |

## 浏览器兼容性

支持的浏览器：
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

推荐使用Chrome或Firefox以获得最佳体验。

## 数据说明

### 时间范围

系统支持多种时间范围表达：
- "过去24小时" / "最近24小时"
- "过去一周" / "最近一周"
- "今天" / "昨天"

### 支持的指标

| 中文名称 | 英文简称 | 单位 |
|---------|---------|------|
| pH值 | pH | pH |
| 化学需氧量 | COD | mg/L |
| 总氮 | TN | mg/L |
| 氨氮 | NH3-N | mg/L |
| 总磷 | TP | mg/L |

## 安全说明

- Web界面服务器仅在本地运行（localhost）
- 不建议在生产环境中直接暴露到公网
- 建议使用反向代理（如Nginx）进行部署
- 请妥善保管API密钥，不要提交到版本控制系统
