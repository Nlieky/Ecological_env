# 废水虚假排放监测专利 - 系统架构部分（最终版）

一种多智能体协同的废水虚假排放智能监测方法及系统，包括人机交互层、监管平台数据采集层、主智能体层、任务编排层、子智能体层、数据与支撑层；

所述人机交互层用于接收监管人员的自然语言指令并将指令转化为结构化数据传递给主智能体层，以及将主智能体层输出的分析结果转化为可视化报告向监管人员展示；

所述监管平台数据采集层负责通过部署在排污口的在线监测设备实时采集废水排放指标数据，并将原始监测数据传递给数据与支撑层进行存储；

所述主智能体层作为系统全局决策中枢，利用大语言模型的语义理解能力对自然语言指令和监测触发信号进行解析，通过任务分解将复杂指令拆解为原子任务，通过结果复用判决判断历史结果可复用性，通过调度决策生成结构化调度策略并下发至任务编排层；

所述任务编排层作为结构化执行枢纽，不依赖大语言模型参与决策，负责将主智能体层的调度决策转化为可执行的任务链，通过任务结构化生成标准化任务格式，通过任务流生成构建有向无环图执行流程，通过资源匹配完成任务到子智能体的分配，通过执行控制监控任务执行状态；

所述子智能体层由数据治理子智能体、特征与关系分析子智能体、异常检测子智能体、规则推理子智能体构成，用于驱动各专业子智能体执行具体任务，通过标准化接口实现子智能体之间的数据流转与协作；

所述数据与支撑层为全系统提供底层支撑，通过时序监测数据库存储原始监测数据、特征数据与分析结果，通过废水排放知识库存储法规标准、工艺机理与专家经验，通过异常检测模型算子库提供可调用的异常检测算法，通过迭代更新接口支持系统模型与规则的动态优化。

## 各层模块详细描述

所述人机交互层包括自然语言交互模块和可视化报告展示模块；

所述自然语言交互模块提供自然语言输入接口，接收监管人员输入的口语化查询指令，支持的查询场景包括违规检测、趋势分析、相关性分析、状态查询、报告生成，输入指令长度限制为500字符，采用WebSocket协议实现与主智能体层的实时通信；所述可视化报告展示模块将主智能体层输出的分析结果转化为图表、文字、告警信息等可视化形式，通过Web界面、移动端应用、大屏展示系统向监管人员呈现，具体的：图表类型包括时序曲线图、散点图、热力图、柱状图，告警信息按照嫌疑等级分为高风险、中风险、低风险三种颜色标识，高风险采用红色，中风险采用橙色，低风险采用黄色；

所述监管平台数据采集层包括数据采集适配模块和数据传输模块；

所述数据采集适配模块通过标准通信协议对接部署在排污口的在线监测设备，支持的通信协议包括HJ 212-2017、Modbus、OPC UA，支持的监测指标包括pH值、化学需氧量、氨氮浓度、总氮浓度、总磷浓度、悬浮物浓度、流量、排放量，数据采集频率预设为每2秒一次，取值范围为[1秒, 60秒]；所述数据传输模块将采集的原始监测数据按照HJ 212-2017污染源在线监控（监测）系统数据传输标准封装为数据包，通过物联网网关采用MQTT协议传输至数据与支撑层，数据包包含字段为：监测点编码、设备ID、指标名称、监测数值、时间戳、数据质量标识、设备状态码；

所述主智能体层包括任务接收与解析模块、任务分解模块、结果复用判决模块、调度决策模块、结果解释输出模块、自适应优化模块；

所述任务接收与解析模块用于接收两种类型的输入信号并进行解析处理，第一种输入为自然语言指令，第二种输入为监测触发信号；具体的：对于自然语言指令，采用大语言模型进行意图识别与实体提取，意图类型包括analysis_query、violation_detection、trend_analysis、correlation_analysis、status_query、report_generation、alert_config、feedback_submission共8类，意图识别置信度阈值预设为0.85，取值范围为[0.8, 0.95]；实体提取包括监测指标、时间范围、监测点位，提取的指标包括pH、COD、NH3-N、TN、TP、SS、flow；对于监测触发信号，接收来自监管平台的JSON格式结构化触发信号，直接解析为标准化监测任务，触发信号包含监测点位、指标列表、采样间隔、监测时间窗口、数据质量要求字段；

所述任务分解模块将复杂任务拆解为可执行的原子任务序列并建立任务间的依赖关系；具体的：基于意图类型到原子任务的映射规则，violation_detection意图映射为[data_governance, feature_analysis, anomaly_detection, rule_reasoning]四个原子任务，trend_analysis意图映射为[data_governance, feature_analysis]两个原子任务，status_query意图映射为[data_governance]一个原子任务；通过有向无环图（DAG）构建算法生成任务依赖图，采用拓扑排序算法确定执行顺序，为每个原子任务分配优先级，优先级取值范围为[1, 10]，数值越大优先级越高；

所述结果复用判决模块用于判断查询任务是否可复用历史分析结果，包括数据匹配、新鲜度判断和语义匹配三个维度的判决逻辑；

所述数据匹配判决采用Jaccard相似系数算法计算查询指标集合与历史结果指标集合的相似度，结合时间重叠度和位置匹配度生成综合数据匹配度；具体的：对于数据匹配度M的计算公式如下：

M = w₁·M_ind + w₂·M_time + w₃·M_loc

其中，M_ind代表指标相似度，采用Jaccard相似系数计算，公式为M_ind = |I_q ∩ I_r| / |I_q ∪ I_r|，I_q为查询指标集合，I_r为历史结果指标集合，取值范围为[0,1]；M_time代表时间重叠度，公式为M_time = overlap(T_q, T_r) / union(T_q, T_r)，T_q和T_r分别为查询时间区间和历史结果时间区间，overlap为时间区间交集长度，union为时间区间并集长度，取值范围为[0,1]；M_loc代表位置匹配度，查询点位与历史点位完全相同时为1，否则为0；w₁、w₂、w₃分别代表指标、时间、位置的权重系数，预设值分别为0.4、0.3、0.3，取值范围均为[0.1, 0.6]；当M ≥ θ_M时数据匹配通过，触发新鲜度判断，否则输出重新计算指令，其中θ_M为数据匹配阈值，预设值为0.7，取值范围为[0.5, 0.9]；

所述新鲜度判决根据任务类型设定不同的时间窗口并判断历史结果是否处于有效时间窗口内；具体的：计算缓存时间差Δt = t_now - t_result，单位为秒，根据任务类型从时间窗口配置表中获取窗口大小W_task，当Δt ≤ W_task时新鲜度通过，触发语义匹配判断，否则输出重新计算指令；时间窗口配置表如下：data_governance任务窗口为3600秒，feature_analysis任务窗口为3600秒，anomaly_detection任务窗口为1800秒，rule_reasoning任务窗口为7200秒；时间窗口设定依据为：原始数据变化较慢设定1小时，异常状态需及时发现设定30分钟，法规知识相对稳定设定2小时；

所述语义匹配判决计算查询任务与历史结果的语义相似度，包括意图类型匹配、分析目标语义相似度和输出类型兼容性；具体的：对于语义匹配度S的计算公式如下：

S = w_i·S_intent + w_g·S_goal + w_o·S_output

其中，S_intent代表意图类型匹配度，意图类型完全一致时为1，否则为0；S_goal代表分析目标语义相似度，采用编辑距离算法计算，公式为S_goal = 1 - edit_dist(G_q, G_r) / max_len(G_q, G_r)，G_q和G_r分别为查询分析目标和历史分析目标，edit_dist为编辑距离，max_len为较长文本的长度，取值范围为[0,1]；S_output代表输出类型兼容性，report与card兼容性预设为0.8，report与data兼容性预设为0.5，card与data兼容性预设为0.7，其他为0.3；w_i、w_g、w_o分别代表意图、目标、输出的权重系数，预设值分别为0.5、0.3、0.2，取值范围分别为[0.3, 0.7]、[0.1, 0.5]、[0.1, 0.3]；当S ≥ θ_S时语义匹配通过，输出复用指令，否则输出重新计算指令，其中θ_S为语义匹配阈值，预设值为0.8，取值范围为[0.6, 0.95]；

所述调度决策模块根据原子任务集合和复用判决结果生成全局调度策略；具体的：当复用判决为重新计算时，根据任务依赖关系生成执行顺序，为每个任务分配目标子智能体；当复用判决为复用时，直接返回历史结果；通过优先级计算公式确定任务执行顺序，优先级P的计算公式为P = w_p·task_priority + w_t·(1/elapsed_time) + w_d·is_on_critical_path，其中w_p、w_t、w_d分别为优先级权重、等待时间权重、关键路径权重，预设值分别为0.6、0.2、0.2；

所述结果解释输出模块将子智能体层输出的技术分析结果转化为自然语言报告；具体的：采用大语言模型生成自然语言描述，报告结构包括监测概况、分析结果、违规判定、取证建议四个部分，监测概况包含监测点位、时间范围、涉及指标，分析结果包含数据质量评估、特征分析发现、异常检测结果，违规判定包含嫌疑等级、违规类型、证据链，取证建议包含需核查的数据点、需调取的证据、适用法规条款；

所述自适应优化模块根据监管反馈自动更新系统参数、规则和模型；具体的：收集反馈类型包括confirm、false_positive、false_negative、correction四种，统计反馈分布计算置信度；当误报率超过预设阈值θ_fp时，θ_fp预设值为0.15，取值范围为[0.1, 0.3]，降低异常检测阈值，调整公式为new_threshold = old_threshold × (1 + α)，α为调整系数，预设值为0.1，取值范围为[0.05, 0.2]；当漏报率超过预设阈值θ_fn时，θ_fn预设值为0.1，取值范围为[0.05, 0.2]，提高异常检测阈值，调整公式为new_threshold = old_threshold × (1 - α)；当同一修正模式出现次数≥N_rule时，N_rule预设值为5，取值范围为[3, 10]，生成新规则并添加到规则库；

所述任务编排层包括任务结构化模块、任务流生成模块、资源匹配模块和执行控制模块；

所述任务结构化模块将主智能体层的调度指令转化为标准化任务格式；具体的：采用JSON Schema定义任务输入输出约束，包含字段为task_id、task_type、input_spec、output_spec、timeout、max_retries，timeout预设值为300秒，取值范围为[60秒, 600秒]，max_retries预设值为3，取值范围为[1, 5]；

所述任务流生成模块基于任务依赖关系构建有向无环图（DAG）并生成分层执行计划；具体的：采用拓扑排序算法将任务划分为可并行执行的层级，同一层级的任务可并行执行，不同层级的任务按拓扑顺序串行执行；

所述资源匹配模块计算任务与子智能体的匹配评分；具体的：匹配评分公式为score(task, agent) = w_c·capability_match + w_l·(1 - agent.load) + w_q·(1 - agent.queue_length / Q_max)，其中w_c、w_l、w_q分别为能力匹配权重、负载权重、队列权重，预设值分别为0.5、0.3、0.2，capability_match为1时表示智能体具备执行该任务的能力否则为0，agent.load为智能体负载率取值范围为[0, 1]，agent.queue_length为任务队列长度，Q_max为最大队列长度预设值为10；

所述执行控制模块监控任务执行状态并处理异常；具体的：定义任务状态为PENDING、RUNNING、COMPLETED、FAILED、CANCELLED五种，通过状态机管理状态转换；当任务执行时间超过timeout时强制终止并更新状态为FAILED，当子智能体无响应超过60秒时重试1次，仍失败则标记为错误；

所述子智能体层包括数据治理子智能体、特征与关系分析子智能体、异常检测子智能体和规则推理子智能体；

所述数据治理子智能体包括多源数据获取模块、时序对齐与规整模块、数据清洗与质控模块和标准化与归一化模块；

所述多源数据获取模块从数据与支撑层的时序监测数据库读取原始监测数据，验证数据格式符合HJ 212-2017标准，剔除重复上报的同一时间戳数据包；

所述时序对齐与规整模块完成时间戳统一与重采样，将不同频率数据规整为同一时间间隔；具体的：重采样频率预设为1分钟，取值范围为[30秒, 5分钟]，采用现有的线性插值算法填充缺失数据点，对断点进行补齐保证时序连续性；

所述数据清洗与质控模块剔除异常值和噪声；具体的：采用现有的四分位距（IQR）方法检测异常值，IQR = Q3 - Q1，下界为Q1 - 1.5×IQR，上界为Q3 + 1.5×IQR，超出上下界的数据点标记为异常值；采用现有的滑动窗口滤波算法去除噪声，窗口大小预设为5个数据点，取值范围为[3, 10]；

所述标准化与归一化模块消除指标量纲差异；具体的：采用现有的Z-score标准化方法，公式为z = (x - μ) / σ，其中x为原始值，μ为均值，σ为标准差，当σ < 1e-8时直接返回x - μ；

所述特征与关系分析子智能体包括时序特征提取模块、指标相关性分析模块、趋势与滞后分析模块和特征融合与优化模块；

所述时序特征提取模块从标准化时序数据中提取波动、趋势、突变特征；具体的：提取统计特征包括均值、标准差、变异系数、偏度、峰度，提取时序特征包括一阶差分、二阶差分、自相关系数，自相关系数的滞后阶数预设为[1, 2, 3, 5, 10]，滑动窗口大小预设为30个数据点，取值范围为[20, 60]；

所述指标相关性分析模块采用现有的Pearson相关系数算法计算指标间关联关系；具体的：Pearson相关系数的取值范围为[-1, 1]，-1表示完全负相关，0表示无相关，1表示完全正相关；

所述趋势与滞后分析模块采用现有的交叉相关函数（CCF）分析指标间的滞后关系；具体的：计算滞后阶数k从-10到10的交叉相关系数，确定最大相关系数对应的滞后阶数为最优滞后，当最大相关系数的绝对值≥0.3时判定存在显著滞后关系；

所述特征融合与优化模块将多维度特征融合为特征向量；具体的：采用现有技术的主成分分析（PCA）降维，PCA保留95%的方差，融合后的特征向量维度为128维，取值范围为[64, 256]；

所述异常检测子智能体包括算子调用与适配模块、异常评分计算模块、异常模式识别模块和可信度评估模块；

所述算子调用与适配模块根据特征与关系分析子智能体的输出结果选择最优异常检测算子；具体的：当样本量n < 1000且自相关性较弱时选择IQR或3σ方法，当1000 ≤ n < 10000且存在显著时序依赖时选择现有技术的孤立森林算法，当n ≥ 10000且存在显著时序依赖时选择现有技术的LSTM自编码器算法，当傅里叶变换检测到显著周期模式时选择季节性分解结合异常检测，当主成分分析后特征维度仍大于50时选择多变量异常检测算法；孤立森林的污染率参数contamination预设值为0.1，取值范围为[0.05, 0.2]；

所述异常评分计算模块计算异常分数并定位异常时刻；具体的：以孤立森林算法为例，异常分数s的取值范围为[0, 1]，值越大越异常，采用0.5作为异常判定阈值，当s ≥ 0.5时标记为异常；以LSTM自编码器算法为例，计算重构分数reconstruction_error，重构误差越大越异常，采用重构误差的95%分位数作为异常判定阈值，当reconstruction_error ≥ threshold时标记为异常；

所述异常模式识别模块将异常点匹配到数据层面的异常特征；具体的：异常特征定义库包括平稳异常特征、突变异常特征、趋势异常特征、周期异常特征、高频波动异常特征共5类数据层面的异常特征；平稳异常特征定义为监测指标在预设时间窗口内标准差低于预设阈值或变异系数低于预设阈值；突变异常特征定义为监测指标在相邻时间点的变化幅度超过预设阈值；趋势异常特征定义为监测指标呈现单向均匀上升或均匀下降，二阶导数接近零；周期异常特征定义为通过傅里叶变换检测到显著的周期性成分；高频波动异常特征定义为在分钟级时间尺度上出现突升突降、异常归零；通过特征匹配算法计算异常特征与各类异常特征的相似度，当相似度≥0.7时判定匹配到该类异常特征，输出异常特征描述；

所述可信度评估模块计算异常结果的置信度；具体的：置信度计算公式为confidence = w_s·anomaly_score + w_c·pattern_similarity，其中w_s、w_c分别为异常分数权重和模式相似度权重，预设值分别为0.6、0.4，置信度取值范围为[0, 1]；

所述规则推理子智能体包括法规规则匹配模块、工艺机理校验模块、专家经验推理模块和违规结论生成模块；

所述法规规则匹配模块调用废水排放知识库中的法规库进行合规性校验；具体的：法规库包括《水污染防治法》和HJ 915-2017地表水自动监测技术规范，将监测数据与法规标准进行比对，当指标浓度超过排放标准时判定为违规；

所述工艺机理校验模块基于生化处理工艺的物理化学机理判断指标关系是否违背正常规律，并接收异常检测子智能体输出的异常特征描述，结合废水排放知识库中的违规模式特征库进行业务层面的违规判定；具体的：工艺规则库包括pH-COD协同规则、氨氮-总氮转化规则、溶解氧-污染物降解规则、质量平衡规则；违规模式特征库包括人工拟合模式、插瓶干扰模式、稀释排放模式、恶意逃避模式共4类业务层面的违规模式；对于pH-COD协同规则，当pH标准差std_pH < θ_low且COD标准差std_COD > θ_high时，结合异常检测子智能体输出的平稳异常特征，判定为插瓶干扰模式，其中θ_low为pH标准差阈值预设值为0.1，取值范围为[0.05, 0.2]，θ_high为COD标准差阈值预设值为5.0mg/L，取值范围为[3.0, 10.0]mg/L；对于质量平衡规则，计算理论去除率η_theoretical和实际去除率η_actual，当|η_theoretical - η_actual| / η_theoretical > θ_η时，结合异常检测子智能体输出的趋势异常特征或突变异常特征，判定为稀释排放模式，其中θ_η为去除率偏差阈值预设值为0.2，取值范围为[0.1, 0.3]；对于趋势异常特征，结合工况数据监测企业申报的生产状态与设施运行状态，当工况无变化而数据呈现均匀上升或均匀下降时，判定为人工拟合模式；对于排放数据正常但企业申报停产或设施停运的情况，判定为恶意逃避模式；

所述专家经验推理模块调用废水排放知识库中的专家经验库与案例库进行模式匹配与嫌疑判定；具体的：专家经验库包含已确认的违规案例特征和误报案例特征，案例库包含历史违规案例，通过相似度匹配算法计算当前异常与历史案例的相似度，当相似度≥0.8时判定为同类违规；

所述违规结论生成模块输出违规语义判定结果、嫌疑等级和取证要点；具体的：嫌疑等级判定规则为，高风险定义为异常模式匹配数量≥2且存在工艺机理违背，中风险定义为异常模式匹配数量=1且存在工艺机理违背，低风险定义为仅存在异常模式匹配但无机理违背，取证要点包括异常时间段、异常指标、异常类型、适用法规条款；

所述数据与支撑层包括时序监测数据库、废水排放知识库、异常检测模型算子库和迭代更新接口；

所述时序监测数据库采用时序数据库存储原始监测数据、特征数据和分析结果；具体的：原始数据表包含字段为timestamp、location、indicator、value、quality_flag、source，按timestamp+location+indicator建立复合索引；分析结果表包含字段为result_id、query_hash、time_range、indicators、result_data、created_at、expires_at，按query_hash和created_at建立索引以支持结果复用查询；

所述废水排放知识库存储法规标准、工艺机理、违规模式和专家经验；具体的：法规库包含《水污染防治法》条款和排放标准数值，工艺知识库包含生化处理工艺规则、物化处理工艺规则，违规模式特征库包含人工拟合模式、插瓶干扰模式、稀释排放模式、恶意逃避模式共4类业务层面的违规模式的特征描述，专家经验库包含典型违规案例特征、误报案例特征，案例库包含历史违规案例，知识采用三元组(实体, 属性, 值)形式存储；

所述异常检测模型算子库提供可调用的异常检测算法；具体的：算子库分为统计类、机器学习类、深度学习三类，统计类包括3σ方法、IQR方法、Z-score方法、Grubbs检验，机器学习类包括孤立森林、One-Class SVM、LOF、ABOD，深度学习类包括LSTM自编码器、VAE、GAN；

所述迭代更新接口接收主智能体层的更新指令并执行持久化；具体的：支持的更新操作包括add_rule、update_threshold、update_model、delete_rule，每次更新操作记录到日志系统，更新后自动选取历史异常任务进行模拟验证，验证通过后正式发布。
