# 废水监测系统架构说明

## 核心框架

```
LLM驱动主智能体（Hermes框架）
    ├── 意图识别（理解用户查询/数据信号）
    ├── 逻辑推理（规划执行策略）
    └── 子智能体调度（按需选择4个子智能体）
            ↓
4个子智能体（专业执行）
├── 多维数据感知子智能体 → 接入 shared/data/
├── 异常检测子智能体 → 调用 shared/operators/
├── 规则推理子智能体 → 调用 shared/knowledge/
└── 研判预警与处置执行子智能体
            ↓
三库支撑（全局共享资源）
├── 数据库 (shared/data/)
├── 算子库 (shared/operators/)
└── 知识库 (shared/knowledge/)
```

## Hermes框架

主智能体基于Hermes框架实现：
- Agent抽象
- 工具集成
- 子智能体通信
- LLM协调

## 子智能体职责

### 1. 多维数据感知子智能体 📊

- 数据获取：接入 shared/data/historical/
- 数据预处理：清洗、对齐、标准化
- 输出：标准化时序数据

### 2. 异常检测子智能体 🔍

- 算子调用：从 shared/operators/ 调用检测算子
- 异常识别：5类异常模式
- 违规检测：4类违规模式
- 输出：异常检测结果

### 3. 规则推理子智能体 ⚖️

- 知识调用：从 shared/knowledge/ 调用法规/工艺/专家经验
- 规则推理：合规性校验、工艺机理校验
- 违规判定：语义层面违规结论
- 输出：违规判定结果

### 4. 研判预警与处置执行子智能体 🚨

- 融合共识：综合异常检测和规则推理
- 预警分级：一般/较重/严重
- 工单生成：包含核查要点、法规条款
- 输出：预警信息和处置工单
