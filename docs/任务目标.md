# 任务目标文档

## 项目概述

**项目名称**：废水虚假排放智能监测系统

**专利基础**：《一种多智能体协同的废水虚假排放智能监测方法及系统》

**项目目标**：基于专利要求，构建完整的多智能体协同废水虚假排放智能监测系统，实现对插瓶干扰、暗管偷排、清水稀释排放、数据篡改等违规行为的精准识别。

---

## 核心业务目标

### 识别的违规行为

1. **插瓶干扰**：使用标准溶液模拟达标排放
2. **暗管偷排**：未经监测直接排放
3. **清水稀释排放**：在排放口加清水稀释降低浓度
4. **数据篡改**：人为修改监测数据
5. **虚假停产**：虚假报告停产状态
6. **工况造假**：伪造设备运行状态
7. **违背工艺机理的隐蔽违规**：数据不符合污水处理工艺规律

# 实时监测模式实施计划

## 一、架构理解

### 核心理念
大模型作为核心协调器，读取主智能体和子智能体的完整身份信息：

1. **大模型读取主智能体完整身份**：
   - workspace/IDENTITY.md
   - workspace/AGENTS.md
   - workspace/MEMORY.md
   - workspace/HEARTBEAT.md
   - workspace/TOOLS.md
   - workspace/skills/orchestrator-core/SKILL.md（核心技能）

2. **使用现有orchestrator-core模块**：
   - 任务接收与解析（需创建，由大模型处理）
   - 任务结构化（已有）
   - 任务流生成（已有）
   - 资源匹配（已有）
   - 执行控制（已有）

3. **大模型协调子智能体**（不需要额外脚本）：
   - 大模型读取任务分配
   - 大模型读取子智能体完整身份：
     - SKILL.md
     - AGENTS.md
     - SOUL.md
     - MEMORY.md
   - 大模型调用已开发的脚本（skills/xxx-core/scripts/*.py）
   - 处理结果传给下一个子智能体

4. **大模型生成结果解释**：
   - 结合所有信息
   - 读取知识库
   - 生成自然语言报告
