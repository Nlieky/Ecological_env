# 错误码定义

## 系统级错误 (E0xxx)

| 错误码 | 描述 | 处理方式 |
|--------|------|----------|
| E0001 | 输入数据格式错误 | 返回错误，不重试 |
| E0002 | 数据获取失败 | 重试3次 |
| E0003 | 算子调用失败 | 降级执行 |
| E0004 | 超时 | 返回部分结果 |
| E0005 | 知识库查询失败 | 使用默认规则 |
| E0006 | 配置错误 | 返回错误，需人工介入 |
| E0007 | 系统资源不足 | 降级服务 |

## 数据治理子智能体错误 (E1xxx)

| 错误码 | 描述 | 处理方式 |
|--------|------|----------|
| E1001 | 数据源不可用 | 切换备用数据源 |
| E1002 | 时序对齐失败 | 返回原始数据 |
| E1003 | 数据质量过低 | 标记并继续 |
| E1004 | 标准化处理失败 | 跳过标准化 |
| E1005 | 时间范围无效 | 返回错误 |

## 特征分析子智能体错误 (E2xxx)

| 错误码 | 描述 | 处理方式 |
|--------|------|----------|
| E2001 | 特征提取失败 | 使用基础特征 |
| E2002 | 相关性计算失败 | 跳过相关性分析 |
| E2003 | 趋势分析失败 | 使用历史趋势 |
| E2004 | 特征融合失败 | 返回各特征独立结果 |

## 异常检测子智能体错误 (E3xxx)

| 错误码 | 描述 | 处理方式 |
|--------|------|----------|
| E3001 | 算子加载失败 | 使用备用算子 |
| E3002 | 检测执行失败 | 降级到统计方法 |
| E3003 | 评分计算失败 | 返回二分类结果 |
| E3004 | 模式识别失败 | 返回通用异常标签 |
| E3005 | 置信度评估失败 | 使用默认置信度 |

## 规则推理子智能体错误 (E4xxx)

| 错误码 | 描述 | 处理方式 |
|--------|------|----------|
| E4001 | 法规匹配失败 | 使用通用法规 |
| E4002 | 工艺校验失败 | 跳过工艺校验 |
| E4003 | 经验推理失败 | 使用默认规则 |
| E4004 | 结论生成失败 | 返回原始异常 |

## 任务编排层错误 (E5xxx)

| 错误码 | 描述 | 处理方式 |
|--------|------|----------|
| E5001 | 任务结构化失败 | 返回原始任务 |
| E5002 | 任务流生成失败 | 使用默认流程 |
| E5003 | 资源匹配失败 | 队列等待 |
| E5004 | 执行控制失败 | 中断任务 |

## 主智能体层错误 (E6xxx)

| 错误码 | 描述 | 处理方式 |
|--------|------|----------|
| E6001 | 自然语言理解失败 | 使用默认意图 |
| E6002 | 任务分解失败 | 使用原子任务 |
| E6003 | 调度决策失败 | 使用默认调度 |
| E6004 | 结果解释失败 | 返回原始结果 |
