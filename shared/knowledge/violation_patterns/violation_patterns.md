# 违规模式特征库

## 一、4类违规模式（专利要求）

### 1.1 插瓶干扰 (Bottle Substitution)

**定义**: 使用标准溶液模拟达标排放，使监测数据呈现恒定值

**特征**:
- 单个或多个指标长时间保持恒定
- 恒定值接近标准限值（如COD=45mg/L接近一级A标50mg/L）
- 标准差异常低（std < 0.1）
- 其他指标保持正常波动

**检测逻辑**:
```python
if 指标恒定时长 > 阈值 AND 恒定值接近标准限值:
    判定为插瓶干扰
```

**标准限值**（GB 18918-2002 一级A标）:
- COD: 50 mg/L
- TN: 15 mg/L
- NH3-N: 5 mg/L
- TP: 0.5 mg/L
- pH: 6-9

---

### 1.2 人工拟合 (Artificial Fitting)

**定义**: 数据经过人工处理呈现异常平滑的数学函数特征

**特征**:
- 数据变化过于平滑，差分标准差异常小
- 变化模式符合数学函数（线性、指数等）
- R²值异常高（>0.95）
- 缺乏真实数据的随机波动

**检测逻辑**:
```python
smoothness = diff_std / series_std
if smoothness < 0.3 AND R² > 0.95:
    判定为人工拟合
```

---

### 1.3 稀释排放 (Dilution Discharge)

**定义**: 在排放口加清水稀释降低污染物浓度

**特征**:
- 多指标同步下降
- 浓度处于异常低位（<历史中位数50%）
- 水量数据异常增加（如果有）
- 去除率异常（理论值与实际值偏差>20%）

**检测逻辑**:
```python
declining_count = 统计(斜率 < -0.1)
low_count = 统计(当前值 < 历史中位数 * 0.5)

if declining_count / 总指标数 > 0.6 AND low_count / 总指标数 > 0.5:
    判定为稀释排放
```

**质量平衡规则**:
```
η_theoretical = (C_influent - C_effluent) / C_influent
η_actual = 实际去除率

if |η_theoretical - η_actual| > 0.2 AND (趋势异常 OR 突变异常):
    判定为稀释排放模式
```

---

### 1.4 恶意逃避 (Malicious Evasion)

**定义**: 不正常运行监测设备逃避监管

**特征**:
- 数据缺失率异常（>20%）
- 夜间数据缺失率明显高于日间
- 监测设备频繁离线
- 特定时段数据空白

**检测逻辑**:
```python
missing_rate = 缺失值数量 / 总数量
night_missing_rate = 夜间缺失率
day_missing_rate = 日间缺失率

if missing_rate > 0.2 OR night_missing_rate > day_missing_rate * 2:
    判定为恶意逃避
```

## 二、工艺规则库

### 2.1 pH-COD协同规则

```python
if std_pH < 0.1 AND std_COD > 5.0:
    # pH稳定但COD波动大
    判定为插瓶干扰异常
```

### 2.2 氨氮-总氮转化规则

```python
if NH3_N浓度异常 AND TN浓度正常:
    # 违背氮转化规律
    标记为可疑
```

### 2.3 溶解氧-污染物降解规则

```python
if DO浓度正常 AND 污染物浓度不降反升:
    # 违背降解规律
    标记为可疑
```

### 2.4 质量平衡规则

```python
质量平衡误差 = |输入质量 - 输出质量 - 去除质量| / 输入质量

if 质量平衡误差 > 阈值:
    标记为可疑
```

## 三、嫌疑等级判定（专利要求）

| 条件 | 嫌疑等级 |
|------|----------|
| 异常模式匹配数量≥2 且 存在工艺机理违背 | 高风险 (红色) |
| 异常模式匹配数量=1 且 存在工艺机理违背 | 中风险 (橙色) |
| 仅存在异常模式匹配但无机理违背 | 低风险 (黄色) |
