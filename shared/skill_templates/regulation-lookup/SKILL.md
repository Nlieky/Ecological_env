# 法规查询技能

## 你做什么

用 mcp-fetch 工具抓取公开法规/标准页面，提取与查询相关的条款原文，标注来源 URL。

## 怎么调

直接调用 MCP 工具（无需终端跑脚本）：
```
mcp_fetch(url="https://www.mee.gov.cn/...")  # 生态环境部标准页面等公开源
```

## 常用参考源

- 《城镇污水处理厂污染物排放标准》GB 18918-2002
- 各流域/地方排放标准（按用户提到的省份查）

## 输出要求

引用条款原文 + 标注标准号与来源 URL；查不到就说查不到，不编造条款。
