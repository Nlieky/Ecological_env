# 研判预警与处置执行子智能体 - 专业记忆

## 预警分级标准

### Critical (紧急/4级)
**触发条件**：
- 高风险违规 + 高置信度(≥0.9)
- 插瓶干扰/恶意逃避类型
- 多项证据确凿

**响应要求**：
- 响应时限：立即（<30分钟）
- 推送对象：监管领导、现场检查组
- 推送方式：短信+电话+APP

### Error (严重/3级)
**触发条件**：
- 高/中风险违规 + 中高置信度(≥0.7)
- 稀释排放/人工拟合类型
- 证据链较完整

**响应要求**：
- 响应时限：2小时
- 推送对象：执法人员、现场检查组
- 推送方式：短信+邮件+APP

### Warning (警告/2级)
**触发条件**：
- 中风险违规 + 中等置信度(≥0.5)
- 异常模式初步识别
- 需要进一步核查

**响应要求**：
- 响应时限：24小时
- 推送对象：执法人员
- 推送方式：邮件+APP

### Info (提示/1级)
**触发条件**：
- 低风险或低置信度(<0.5)
- 可能是正常工况波动
- 需要持续观察

**响应要求**：
- 响应时限：72小时
- 推送对象：系统用户
- 推送方式：APP

## 融合共识算法

### 置信度融合
```
综合置信度 = (anomaly_confidence × 0.4) + (violation_confidence × 0.6)
```

### 等级调整
- 综合置信度 ≥ 0.9: 等级 × 1.2（上浮）
- 综合置信度 0.7-0.9: 等级 × 1.0（保持）
- 综合置信度 < 0.7: 等级 × 0.8（下浮）

### 多证据支持
当多个独立证据指向同一违规类型时，提升预警等级：
- 2个证据支持: 等级 +0.5
- 3个及以上证据支持: 等级 +1.0

### 标准化处置建议

#### 插瓶干扰
1. 检查采样探头位置（是否在采样管内）
2. 核查采样管路完整性（是否有旁路）
3. 检查现场是否有标准溶液（用于插瓶）
4. 核查设备运行记录
5. 现场拍照取证

#### 稀释排放
1. 检查清水接入管路
2. 核对用水量与排水量平衡
3. 检查排放口周边环境
4. 核查药剂投加记录
5. 检查是否有清水稀释装置

#### 人工拟合
1. 检查设备参数设置（是否过度平滑）
2. 核对历史数据记录（数据修改痕迹）
3. 检查数据传输日志
4. 核查原始数据记录
5. 技术鉴定数据分析

#### 恶意逃避
1. 检查数据缺失规律性
2. 核查设备停运记录
3. 检查监测时段规律
4. 现场突击检查
5. 核查生产记录与数据关系

## 处置流程

### 标准流程
```
1. 结果融合 → 2. 预警研判 → 3. 工单生成 → 4. 推送执行 → 5. 跟踪反馈 → 6. 归档闭环
```

### 响应时限跟踪
- 推送确认: <5分钟
- 首次响应: 按预警等级时限
- 处置进度: 每4小时更新
- 闭环确认: 处置完成后24小时内

### 闭环条件
- Critical/Error: 现场核查报告 + 处置决定
- Warning/Info: 核查说明 + 处理结果

## LLM决策范围

- **预警等级判定**: 根据综合置信度和违规类型判定预警等级
- **多证据融合**: 决定是否提升预警等级
- **处置建议生成**: 根据违规类型和历史案例生成处置建议
- **推送对象选择**: 根据预警等级决定推送范围和方式
- **闭环跟踪**: 决定何时确认闭环和归档
