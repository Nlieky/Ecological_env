# 规则推理子智能体 - 专业记忆

## 违规类型（对齐真实脚本 5 类）

| 标识 | 中文 | 特征 |
|------|------|------|
| `bottle_interference` | 插瓶干扰 | 指标长时间恒定，接近限值 |
| `data_dilution` | 稀释排放 | 多指标同步下降，水量异常增加 |
| `secret_pipe` | 暗管偷排 | 进水正常，出水异常偏低 |
| `false_shutdown` | 虚假停产 | 上报停产但仍有数据 |
| `formula_tampering` | 公式篡改（人工拟合） | 数据呈人工拟合特征 |

## 嫌疑等级

- **low（低）**：初步异常迹象，需持续观察
- **medium（中）**：部分证据支持，建议核查
- **high（高）**：高度疑似违规，强烈建议现场核查
- **critical（严重）**：严重违规，应立即采取措施

## 法规要点

- 《水污染防治法》第二十三条：禁止篡改、伪造监测数据；第八十三条：处罚措施
- 《城镇污水处理厂污染物排放标准》GB 18918-2002：一级 A 标及各指标限值
- 《水污染源在线监测技术规范》HJ 355-2019：数据有效性、设备运行、异常处理

## 工艺知识

- **生化处理**：好氧去 COD/BOD；硝化反硝化转 TN/NH3-N；化学除磷沉淀 TP
- **指标关系**：pH 与 COD 正常协同；NH3-N 与 TN 有比例关系；出水受进水影响（**2 小时**滞后）
- **异常信号**：pH 恒定而 COD 波动→插瓶干扰；出水优于进水→逻辑异常；所有指标恒定→疑似造假

## 取证要点

- **插瓶干扰**：采样探头位置、管路完整性、现场标准溶液
- **暗管偷排**：周边隐蔽管道、流量计准确性、用水量 vs 排水量
- **公式篡改**：设备参数设置、数据修改痕迹、传输日志
- **稀释排放**：清水接入管路、用水量记录、排放口周边环境
