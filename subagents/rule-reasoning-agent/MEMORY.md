# 规则推理子智能体 - 专业记忆

## 违规模式（4 类，对标参考资料）

| 模式 | 异常特征组合 | 工艺规则 | 初版状态 |
|------|------------|---------|---------|
| 插瓶干扰 | 平稳(+突变) | pH-COD 协同 / 氨氮-总氮转化 | ✅ 完整 |
| 稀释排放 | 突变(+趋势) | 质量平衡 / 多指标同步突降 | ✅ 完整 |
| 人工拟合 | 趋势 | 趋势异常 + 工况无变化 | ⚠ 简化(缺工况) |
| 恶意逃避 | — | 排放正常 + 企业申报停产 | ❌ TODO(缺停产申报) |

## 工艺规则（4 条，资料精确判据）

| 规则 | 判据 | 异常特征 | 判向 |
|------|------|---------|------|
| pH-COD 协同 | pH std≤0.1 且 COD std≤5.0 mg/L | + 平稳 | 插瓶 |
| 氨氮-总氮转化 | 氨氮突降而总氮基本不变 | + 突变 | 插瓶 |
| 质量平衡 | 去除率偏差 > 0.2 | + 趋势/突变 | 稀释 |
| 多指标同步突降 | 2+ 污染物同步下降 >50% | + 突变 | 稀释 |

质量平衡按 `data_result.metadata.hrt_hours` 做进水出水时间对齐。

## 法规参考

- 《水污染防治法》第二十三条：禁止篡改、伪造监测数据
- 《城镇污水处理厂污染物排放标准》GB 18918-2002：一级 A 标及各指标限值
- 排放标准阈值：pH 6–9 / COD ≤100 / TN ≤20 / NH3-N ≤15 / TP ≤1.0
