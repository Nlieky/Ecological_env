# 规则推理子智能体 - 专业记忆

## 法规库要点

### 《水污染防治法》
- **第二十三条**: 禁止篡改、伪造监测数据
- **第八十三条**: 篡改伪造数据的处罚措施
- **第十条**: 排污单位监测义务

### 《水污染源在线监测技术规范》
- **数据有效性判别**: 数据质量要求
- **设备运行要求**: 监测设备规范
- **异常处理**: 异常情况处理流程

### 《城镇污水处理厂污染物排放标准》
- **一级A标**: 出水最高标准
- **各指标限值**: 具体数值要求
- **采样频率**: 监测频率要求

## 工艺知识要点

### 生化处理原理
- 好氧处理：COD、BOD去除
- 硝化反硝化：TN、NH3-N转化
- 化学除磷：TP沉淀去除

### 指标关系
- 正常情况下，pH与COD应协同变化
- NH3-N与TN有一定比例关系
- 出水指标受进水影响（2-4小时滞后）

### 异常情况
- pH恒定、COD波动：插瓶干扰特征
- 所有指标恒定：可能数据造假
- 出水优于进水：逻辑异常

## 专家经验规则

### 插瓶干扰识别
- pH恒定而其他指标波动
- 恒定值在标准限值内
- 波动指标违背工艺关系

### 暗管偷排识别
- 监测数据正常但周边环境异常
- 流量与浓度不匹配
- 夜间异常波动

### 数据造假识别
- 数据过度平滑
- 异常规律性变化
- 与历史数据差异过大

### 稀释排放识别
- 各指标浓度同步下降
- 流量异常增大
- 污染物总量异常

## 嫌疑等级判定

### 高风险
- 多项证据指向同一违规类型
- 违背明确法规条款
- 典型违规模式完全匹配

### 中风险
- 部分证据支持违规判定
- 需要进一步核查
- 违规模式部分匹配

### 低风险
- 初步异常迹象
- 需要持续观察
- 可能是正常工况波动

## 取证要点

### 插瓶干扰
- 检查采样探头位置
- 核查采样管路完整性
- 检查现场是否有标准溶液

### 暗管偷排
- 排查周边隐蔽管道
- 检查流量计准确性
- 核对用水量与排水量

### 数据造假
- 检查设备参数设置
- 核对历史数据记录
- 检查数据修改痕迹

### 稀释排放
- 检查清水接入管路
- 核对用水量记录
- 检查排放口周边环境
