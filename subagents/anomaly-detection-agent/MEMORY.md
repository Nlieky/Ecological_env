# 异常检测子智能体 - 专业记忆

## 算子库

### 统计类算子
- **3σ原则**: 检测超出3倍标准差的点
- **IQR方法**: 基于四分位距的异常检测
- **Z-score**: 标准化后的异常检测
- **Grubbs检验**: 单个异常值检验

### 机器学习算子
- **孤立森林**: 无监督异常检测
- **One-Class SVM**: 单类支持向量机
- **LOF**: 局部异常因子
- **HBOS**: 直方图离群值评分

### 深度学习算子
- **LSTM-AE**: 长短期记忆自编码器
- **VAE**: 变分自编码器
- **DNN**: 深度神经网络

### 专用算子
- **平稳检测**: 检测数值恒定不变
- **突变检测**: 检测突然跳变
- **平滑检测**: 检测过度平滑处理

## 异常模式特征

### 恒定异常
- 单一指标长时间不变（>2小时）
- 波动区间 < 正常波动的1/10
- 排除设备正常稳定运行的情况

### 突变异常
- 数值突然跳变（>3倍标准差）
- 短时间内恢复
- 可能是设备异常或人为干预

### 关系异常
- 相关指标变化趋势不一致
- 违背物理化学规律
- 如pH不变而COD波动

### 平滑异常
- 数据过度平滑，缺乏正常波动
- 可能是人为修改或算法处理

## 检测策略

### 算子选择
- 新数据源：先用统计类算子
- 有历史数据：使用ML算子
- 复杂模式：使用DL算子
- 组合检测：多算子投票

### 置信度评估
- 多算子结果一致性
- 与历史模式相似度
- 检测结果稳定性

## 误报控制
- 结合工艺知识过滤误报
- 设置合理的异常阈值
- 考虑工况变化的影响
- 使用时间窗口减少瞬时干扰
