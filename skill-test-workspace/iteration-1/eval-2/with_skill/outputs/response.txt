## 4. 决策规则应用

### 4.1 pH-COD协同校验规则

### 4.2 异常检测阈值
- **强相关**: |r| >= 0.7
- **中等相关**: 0.4 <= |r| < 0.7
- **弱相关**: 0.2 <= |r| < 0.4
- **几乎无相关**: |r| < 0.2

## 5. 执行控制方案

### 5.1 执行步骤
1. **数据获取** (data-governance-agent)
   - 从监测系统获取最近24小时pH和COD数据
   - 执行时序对齐（确保时间戳一致）
   - 数据清洗（处理缺失值、异常值）
   - 标准化处理

2. **相关性计算** (feature-analysis-agent)
   - 计算皮尔逊相关系数
   - 绘制散点图分析
   - 计算统计显著性（p值）
   - 生成相关性解释

3. **工艺校验** (rule-reasoning-agent)
   - 应用pH-COD协同规则
   - 评估风险等级
   - 生成分析结论
   - 提供建议

### 5.2 降级策略
- **data-governance-agent故障**: 使用缓存数据（如有）
- **feature-analysis-agent故障**: 使用简化相关性计算
- **rule-reasoning-agent故障**: 返回原始相关系数，不进行工艺校验
