## 3. Full Execution Plan for Violation Detection

### Phase 1: Data Collection & Preparation
```
Step 1.1: Query real-time monitoring database for last 24 hours
Step 1.2: Extract time-series data for pH, COD, and Ammonia Nitrogen
Step 1.3: Validate data completeness and quality
Step 1.4: Handle missing or anomalous data points
```

### Phase 2: Single-Point Violation Detection
```
Step 2.1: Check pH values against standard range (6-9)
Step 2.2: Check COD values against discharge limit
Step 2.3: Check Ammonia Nitrogen values against discharge limit
Step 2.4: Flag all individual exceedances with timestamps
```

### Phase 3: Trend & Pattern Analysis
```
Step 3.1: Calculate moving averages for each parameter
Step 3.2: Identify sudden spikes or drops
Step 3.3: Detect abnormal fluctuations (>50% change within 1 hour)
Step 3.4: Analyze diurnal patterns (day vs night)
```

### Phase 4: Fraud Detection Algorithms
```
Step 4.1: Flat-line detection
  - Check for identical consecutive values (>3 consecutive same readings)
  - Identify "stuck sensor" patterns

Step 4.2: Statistical anomaly detection
  - Calculate Z-scores for each parameter
  - Flag readings with |Z-score| > 3
  - Identify values beyond 3-sigma limits

Step 4.3: Correlation analysis
  - Check correlation between parameters
  - Detect abnormal parameter relationships
  - Identify potential data manipulation signatures

Step 4.4: Temporal consistency checks
  - Verify measurement intervals are regular
  - Detect gaps or irregular sampling patterns
  - Check for back-filled or modified data
```

### Phase 5: Regulatory Compliance Assessment
```
Step 5.1: Apply local discharge standards (Hubei Province standards)
Step 5.2: Calculate violation frequency and duration
Step 5.3: Determine violation severity levels
Step 5.4: Generate compliance score
```

### Phase 6: Alert & Report Generation
```
Step 6.1: Compile all detected violations
Step 6.2: Prioritize by severity and environmental impact
Step 6.3: Generate violation report with:
  - Timestamp of each violation
  - Parameter name and measured value
  - Standard limit and exceedance amount
  - Duration of violation (if continuous)
  - Risk level assessment

Step 6.4: Create actionable recommendations
Step 6.5: Format output for regulatory submission
```

## Detection Thresholds Applied

### pH
- **Warning Range**: 6.5-8.5
- **Violation Range**: <6.0 or >9.0
- **Critical Range**: <5.0 or >10.0

### COD (mg/L)
- **Warning Threshold**: 40 mg/L
- **Violation Threshold**: 50 mg/L
- **Critical Threshold**: 100 mg/L

### Ammonia Nitrogen (mg/L)
- **Warning Threshold**: 3 mg/L
- **Violation Threshold**: 5 mg/L
- **Critical Threshold**: 15 mg/L

## Fraud Indicators Monitored

1. **Data Quality Flags**
   - Repeated identical values
   - Impossible values (negative, extreme outliers)
   - Values exactly at limits (suspicious precision)

2. **Temporal Patterns**
   - Regular intervals (suspiciously consistent)
   - Gaps during nighttime hours
   - Sudden changes before/after expected violations

3. **Cross-Parameter Consistency**
   - pH-COD correlation anomalies
   - Temporal misalignment between parameters
   - Physically impossible combinations
