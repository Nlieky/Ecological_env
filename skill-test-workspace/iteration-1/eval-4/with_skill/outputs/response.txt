五、违规检测规则配置
=============================================================================

根据orchestrator-core/references/decision_rules.md，应用的检测规则:

1. 插瓶干扰检测
   触发条件:
   ✓ 指标恒定时长 >= 2小时
   ✓ 指标值在标准限值的80-100%范围内
   ✓ 数据标准差 < 0.1
   判定阈值: 置信度 >= 0.9 (高风险), >= 0.7 (中风险)

2. 稀释排放检测
   触发条件:
   ✓ 多指标同步下降 > 50%
   ✓ 所有指标处于历史低位
   ✓ 去除率异常高 (> 95%)
   判定阈值: 置信度 >= 0.8 (高风险), >= 0.6 (中风险)

3. 人工拟合检测
   触发条件:
   ✓ 数据过度平滑 (标准差异常低)
   ✓ 符合数学函数特征 (线性、多项式)
   ✓ 缺少自然波动
   判定阈值: 置信度 >= 0.8 (高风险), >= 0.6 (中风险)

4. 恶意逃避检测
   触发条件:
   ✓ 数据缺失率异常高 (> 20%)
   ✓ 夜间或特定时段空白模式
   ✓ 设备故障时间与违规时间相关
   判定阈值: 置信度 >= 0.7 (中风险)

工艺机理校验规则:
- pH-COD协同规则: 相关性 >= 0.3为正常
- 质量平衡规则: 进水浓度 * (1 - 去除率) ≈ 出水浓度 (允许误差±20%)

排放标准参考 (GB 18918-2002 一级A标准):
- pH: 6-9
- COD: <= 50 mg/L
- 氨氮: <= 5 mg/L (水温>12℃)
