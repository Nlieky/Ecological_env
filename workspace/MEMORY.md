# 全局长期记忆

## 新架构记忆（2026-05-29更新）

### 子智能体架构
系统采用1主4子架构：
- 主智能体：废水监测主智能体
- 子智能体1：多维数据感知智能体（multi-dimensional-data-perception-agent）
- 子智能体2：异常检测子智能体（anomaly-detection-agent）
- 子智能体3：规则推理子智能体（rule-reasoning-agent）
- 子智能体4：研判预警与处置执行智能体（disposition-execution-agent）

### 子智能体调用方式（2026-06-24更新：文件状态共享）

主智能体通过 **orchestrator-core 技能** 调用子智能体：

**可用工具**：
- `create_session()` - 创建会话目录（workspace/state/session_YYYYMMDD_HHMMSS/）
- `call_subagent(name, task, context)` - 调用子智能体
- `cleanup_sessions(days)` - 清理旧会话

**调用流程**：
```
1. create_session() → 创建会话目录
2. call_subagent("data-perception", task, context) 
   → 写入 task.json
   → 子智能体读取并执行
   → 子智能体写入 data_result.json
   → 主智能体读取结果
3. 继续调用其他子智能体（传递前一步结果作为 context）
4. 整合所有结果，生成最终回答
```

**结果文件映射**：
- data-perception → data_result.json
- anomaly-detection → anomaly_result.json
- rule-reasoning → rule_result.json
- disposition-execution → disposition_result.json

### 数据类型
系统支持8类多维时序数据：
1. 水质数据：pH、COD、TN、TP、氨氮、悬浮物
2. 流量数据：进水流量、出水流量、排放量
3. 设备状态：进水泵、鼓风机、污泥泵状态
4. 工艺参数：溶解氧、污泥浓度、回流比
5. 维护记录：反冲洗、检修、停运计划
6. 生产记录：生产批次、产量变化
7. 污染源信息：名称、行政区划、联系人
8. 监测点信息：名称、编号、类型、级别

### 异常类型（数据层）
1. 平稳异常：恒定值检测
2. 突变异常：突变点检测
3. 趋势异常：趋势违背检测
4. 周期异常：FFT周期检测
5. 高频波动：高频噪声检测

### 违规类型（业务层）
1. 插瓶干扰：恒定值 + 工况正常
2. 人工拟合：过度平滑 + 分布异常
3. 稀释排放：多指标同步下降 + 去除率异常
4. 恶意逃避：数据缺失 + 非工作时间空白

### 预警分级
1. 一般（general）：异常置信度<0.6
2. 较重（moderate）：异常置信度0.6-0.8
3. 严重（serious）：异常置信度>0.8

### 废水处理工艺流程

```
进水 → 粗格栅 → 细格栅 → 初沉池 → 生物反应池 → 二沉池 → 出水
        ↓         ↓         ↓          ↓         ↓        ↓
      监测点1   监测点2   监测点3    监测点4   监测点5  监测点6
```

### 关键时间滞后（水力停留时间）

| 处理单元 | 停留时间 | 说明 |
|---------|---------|------|
| 粗格栅→细格栅 | 0.5小时 | 物理处理 |
| 细格栅→初沉池 | 1小时 | 沉淀处理 |
| 初沉池→生物反应池 | 0.5小时 | 生物处理入口 |
| 生物反应池→二沉池 | 2-3小时 | 核心处理 |
| 二沉池→出水 | 0.5小时 | 最终沉淀 |
| **总计** | **4-5.5小时** | 进水到出水总时间 |

**影响**：分析进水-出水关系时，必须进行时间对齐，否则去除率计算错误。

## 三、4个子智能体职责分工（新架构）

### 1. 多维数据感知智能体 (multi-dimensional-data-perception-agent) 📊

**专业领域**：多维数据获取、治理与感知

**核心职责**：
| 功能 | 说明 | 脚本/方法 |
|------|------|----------|
| 多源数据获取 | 8类数据：水质、流量、设备、工艺、维护、生产、污染源、监测点 | pandas.read_csv, requests.get |
| 时序对齐规整 | 处理水力停留时间滞后（4-5.5小时） | 时间戳偏移、插值 |
| 数据清洗质控 | 缺失值、异常值处理 | 均值填充、3σ原则 |
| 标准化归一化 | 0-1归一化、Z-score | MinMaxScaler, StandardScaler |
| 特征提取 | 时序特征、频域特征、统计特征 | 均值、方差、偏度、峰度、FFT |
| 相关性分析 | 指标间关系分析 | Pearson、Spearman相关 |
| 趋势与滞后分析 | 线性趋势、交叉相关 | numpy.corrcoef |

**输入**：原始8类监测数据（时间戳、监测点位、指标值）
**输出**：清洗对齐后的数据 + 特征矩阵 + 相关性矩阵

**合并说明**：原data-governance-agent与feature-analysis-agent合并，实现从数据获取到特征感知的一体化处理

### 2. 异常检测子智能体 (anomaly-detection-agent) 🔍

**专业领域**：异常检测与违规模式识别

**5类异常模式**：
| 异常类型 | 特征 | 检测方法 |
|---------|------|----------|
| 平稳异常 | 恒定值，标准差极低 | 标准差检测 |
| 突变异常 | 突然跳变 | 变化率检测 |
| 趋势异常 | 持续上升/下降 | 线性回归斜率 |
| 周期异常 | 异常周期模式 | FFT频谱分析 |
| 高频波动异常 | 过度波动 | 方差检测 |

**4类违规模式**：
| 违规类型 | 特征 | 判定阈值 | 置信度 |
|---------|------|---------|--------|
| 插瓶干扰 | 恒定、接近限值 | 恒定≥2h, 值80-100%, std<0.1 | ≥0.9高风险 |
| 稀释排放 | 多指标同步下降 | 降幅≥50%, 去除率>95% | ≥0.8高风险 |
| 人工拟合 | 过度平滑 | R²>0.99 | ≥0.6中风险 |
| 恶意逃避 | 数据缺失规律性 | 缺失率>20% | ≥0.7中风险 |

**输入**：特征矩阵、相关性矩阵
**输出**：异常列表、违规候选列表、置信度

**不负责**：数据获取、特征提取、违规结论生成

### 3. 规则推理子智能体 (rule-reasoning-agent) ⚖️

**专业领域**：规则推理与违规判定

**核心职责**：
| 功能 | 说明 | 规则来源 |
|------|------|----------|
| 法规规则匹配 | 《水污染防治法》、HJ 915-2017 | 法规知识库 |
| 工艺机理校验 | pH-COD协同、氨氮-总氮转化、质量平衡 | 工艺知识库 |
| 专家经验推理 | 相似度匹配、案例对比 | 案例库 |
| 违规结论生成 | 高/中/低风险等级，处理建议 | 综合判定 |

**工艺机理规则**：
| 规则名称 | 判定条件 | 异常标准 |
|---------|---------|---------|
| pH-COD协同 | 相关性检查 | 相关性<0.3为异常 |
| 氨氮-总氮转化 | 相关性、比值检查 | 相关性<0.3或比值∉[20%,60%] |
| 质量平衡 | C_in×(1-η)≈C_out | 误差>±20%为异常 |

**输入**：异常列表、特征矩阵、相关性矩阵
**输出**：违规结论、风险等级、证据链

**不负责**：数据获取、特征提取、异常检测、处置执行

### 4. 研判预警与处置执行智能体 (disposition-execution-agent) 🚨

**专业领域**：研判预警、处置执行与结果反馈

**核心职责**：
| 功能 | 说明 | 方法 |
|------|------|------|
| 研判分析 | 综合异常、违规结论、证据链进行研判 | 多维度综合评估 |
| 预警分级 | 一般/较重/严重三级预警 | 置信度+风险等级 |
| 处置建议生成 | 根据违规类型生成处置建议 | 专家规则库 |
| 执行跟踪 | 处置过程跟踪与结果反馈 | 执行日志 |
| 报告生成 | 自然语言报告、可视化图表 | 模板引擎 |

**预警分级标准**：
| 级别 | 置信度范围 | 处置要求 |
|------|-----------|---------|
| 一般（general） | <0.6 | 持续观察 |
| 较重（moderate） | 0.6-0.8 | 进一步调查 |
| 严重（serious） | >0.8 | 立即上报并现场核查 |

**输入**：违规结论、风险等级、证据链、异常列表
**输出**：研判报告、预警级别、处置建议、执行反馈

**新增能力**：将原主智能体的研判预警与处置执行功能独立为专门的子智能体，实现专业化的闭环管理

## 四、违规模式知识库

### 插瓶干扰

**原理**：将采样管插入装有达标水的瓶子，绕过实际水样采集

**典型特征**：
```
COD值: ─────────────────────── 82-85mg/L ───────────────────────
      (恒定在标准限值100mg/L的80-85%范围)

标准差: < 0.1
持续时间: ≥2小时
```

**判定流程**：
1. 计算指标标准差，std < 0.1
2. 计算指标均值与限值比值，80% ≤ ratio ≤ 100%
3. 检查持续时间，≥2小时
4. 综合置信度 = (平稳度 + 位置度) × 时间因子

**调查建议**：
- 检查采样探头位置
- 核查在线监测设备校准记录
- 调阅视频监控确认采样情况
- 现场突击检查

### 稀释排放

**原理**：在排放口加入清水稀释污染物浓度

**典型特征**：
```
COD:    ╲     (下降50%)
NH3-N:  ╲     (同步下降50%)
TP:     ╲     (同步下降50%)
水量:   ╱     (增加)
```

**判定流程**：
1. 检查多指标同步性，相关系数 > 0.8
2. 计算下降幅度，≥50%
3. 检查去除率，>95%（异常高）
4. 综合置信度 = 同步性 × 降幅 × 去除率异常度

**调查建议**：
- 检查进水水量记录
- 核查处理设施运行状况
- 检查排口附近是否有清水接入
- 检查应急池、雨水管

### 人工拟合

**原理**：人工修改数据使其呈现理想状态

**典型特征**：
```
真实数据:  ╱╲╱╲___╱╱╲___╲╱  (有自然波动)
拟合数据:  ────────────────  (过度平滑)
```

**判定流程**：
1. 计算标准差，异常低
2. 拟合数学函数，R² > 0.99
3. 检查缺失值规律性
4. 综合置信度 = 平滑度 × 拟合度 × 规律性

**调查建议**：
- 分析数据统计特征
- 检查历史数据校准记录
- 与相似企业数据对比
- 检查数据修改日志

### 恶意逃避

**原理**：故意停止监测设备或中断数据传输

**典型特征**：
```
数据完整性: ████████░░░░░░░░  (80%, 正常应>95%)
夜间时段:   ████████████████  (白天正常)
            ░░░░░░░░░░░░░░░░  (夜间空白)
```

**判定流程**：
1. 计算缺失率，>20%
2. 分析缺失时段规律性
3. 检查故障时间与违规时间相关性
4. 综合置信度 = 缺失率 × 规律性 × 相关性

**调查建议**：
- 检查数据传输日志
- 核查设备运行记录
- 调阅监控录像
- 检查设备开关机记录

## 七、工作流程经验

### 标准分析流程

```
1. 多维数据感知
   - 获取8类数据（水质、流量、设备、工艺、维护、生产、污染源、监测点）
   - 时间对齐（水力停留时间4-5.5小时）
   - 数据清洗与标准化
   - 特征提取（时序、频域、统计）
   - 相关性分析

2. 异常检测
   - 检测5类异常模式（平稳、突变、趋势、周期、高频波动）
   - 识别4类违规候选（插瓶干扰、稀释排放、人工拟合、恶意逃避）
   - 计算置信度

3. 规则推理
   - 法规匹配（水污染防治法、HJ 915-2017）
   - 工艺机理校验（pH-COD协同、氨氮-总氮转化、质量平衡）
   - 专家经验推理
   - 生成违规结论与证据链

4. 研判预警与处置执行
   - 综合研判分析
   - 预警分级（一般/较重/严重）
   - 生成处置建议
   - 执行跟踪与反馈
```

### 降级处理经验

| 子智能体故障 | 降级策略 | 效果 |
