# 废水监测系统 - 主智能体记忆

## 子智能体架构

4个子智能体：
1. **multi-dimensional-data-perception** - 数据获取与预处理
2. **anomaly-detection** - 异常检测与违规模式识别
3. **rule-reasoning** - 法规匹配与违规判定
4. **disposition-execution** - 预警分级与处置执行

## 调用方式

```
call_subagent(name, task, context?)
- name: 子智能体名称
- task: 任务描述
- context: 前置结果（可选）
```

## 监测指标

| 指标 | 单位 | 出水限值 |
|------|------|---------|
| pH | - | 6-9 |
| COD | mg/L | ≤100 |
| NH3-N | mg/L | ≤15 |
| TN | mg/L | ≤20 |
| TP | mg/L | ≤1.0 |

## 违规类型

1. **插瓶干扰** - 恒定值（std<0.1）+ 接近限值
2. **稀释排放** - 多指标同步下降50% + 去除率>95%
3. **人工拟合** - 过度平滑（R²>0.99）
4. **恶意逃避** - 数据缺失率>20%

## 水力停留时间

进水→出水总时间：4-5.5小时（分析时需时间对齐）
