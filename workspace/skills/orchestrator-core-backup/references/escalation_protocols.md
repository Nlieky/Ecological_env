# 升级上报流程

## 版本信息

- **版本**: 2.1.0
- **更新日期**: 2026-05-15

## 升级协议定义

### 紧急违规 (URGENT)

**触发条件**:
- 置信度 >= 0.9
- 影响严重（如插瓶干扰、暗管偷排）
- 持续时间 >= 4小时

**处理流程**:
1. 立即生成应急简报
2. 通知监管人员（短信+邮件）
3. 记录到违规案例库
4. 启动应急响应程序

**响应时间要求**:
- 发现后15分钟内生成简报
- 30分钟内通知相关人员

**上报格式**:
```yaml
alert_type: 紧急违规告警
severity: 高风险
title: 疑似插瓶干扰告警
evidence:
  - pH值恒定48小时
  - 值在标准限值的85-90%
investigation_points:
  - 检查采样探头
  - 核查校准记录
  - 调阅监控录像
action_required: 立即现场核查
```

### 可疑异常 (SUSPICIOUS)

**触发条件**:
- 置信度 >= 0.7 且 < 0.9
- 存在多个异常特征
- 需要进一步确认

**处理流程**:
1. 添加到监控列表
2. 持续跟踪（每小时检查）
3. 确认后升级或降级
4. 记录跟踪日志

**响应时间要求**:
- 1小时内添加到监控列表
- 每小时更新状态

### 低置信度 (LOW_CONFIDENCE)

**触发条件**:
- 置信度 < 0.7
- 异常特征不明显
- 可能是正常波动

**处理流程**:
1. 记录日志
2. 不触发告警
3. 持续监测（正常频率）

## 升级路径

```
低置信度异常
    ↓
持续监测（正常频率）
    ↓
发现更多证据 → 可疑异常
    ↓
添加监控列表（每小时）
    ↓
确认高风险 → 紧急违规
    ↓
立即上报 + 应急响应
```

## 降级路径

```
紧急违规
    ↓
现场核查排除违规 → 可疑异常
    ↓
持续监测
    ↓
确认正常 → 低置信度（归档）
```

## 上报对象

| 级别 | 上报对象 | 通知方式 |
|------|---------|----------|
| 紧急违规 | 监管负责人、现场人员 | 短信、邮件、电话 |
| 可疑异常 | 监管负责人 | 邮件、系统消息 |
| 低置信度 | 无 | 仅系统记录 |

## 上报模板

```markdown

## 基本信息
- 生成时间: {timestamp}
- 监测点位: {monitoring_point}

## 异常描述
{anomaly_description}

## 证据信息
{evidence_details}

## 建议措施
{recommendations}

## 联系方式
- 负责人: {contact_person}
- 电话: {phone_number}
```

### 日报模板

```markdown

## 异常统计
- 检测到异常: {count}起
- 高风险: {high}起

## 详细信息
{details}

## 处理状态
- 已处理: {resolved}起
- 处理中: {processing}起
- 待处理: {pending}起
```

## 跟踪要求

### 紧急违规跟踪

- 每30分钟更新一次状态
- 记录所有处理措施
- 处理完成后24小时内生成报告

### 可疑异常跟踪

- 每小时更新一次状态
- 连续24小时无异常后自动归档

### 历史记录

- 所有告警记录保留1年
- 违规案例永久保存
- 处理报告保存5年
